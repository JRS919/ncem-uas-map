# NCEM UAS Team Roster Map

Interactive map of North Carolina UAS (drone) teams from the NCEM UAS roster interest form, showing agency type, drone and software capabilities, and team contacts.

**Live map:** https://jrs919.github.io/ncem-uas-map/

## Updating the roster

1. Export the latest responses from the Microsoft Forms roster form.
2. Save the export as CSV and name it `roster.csv`.
3. In this repository, choose **Add file → Upload files**, drop in the new `roster.csv` (it replaces the old one), and commit.
4. The live map updates within a minute or two.

Keep the column headers from the Forms export as they are; the map finds columns by their header names.
Older duplicate submissions (#18, #23, #30, #31) are hidden by the map.

## Marker colors

- Blue: Law enforcement (including sheriff's offices)
- Red: Fire / rescue
- Half blue, half red: Combined fire and law enforcement teams
- Yellow: Emergency management
- Green: All others
